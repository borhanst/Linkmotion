# Storytelling

Creative skill: narrative structure, hooks, pacing.

## Universal arc

Hook -> what it is -> the proof -> how/why it works -> catch/limits -> verdict.

## Hook

First 2 seconds for Shorts, first 5-10 for long-form. A number or a claim, not
"hello everyone". Open on a stat card, not a title.

## Pacing

- Shorts: pattern interrupt every 6-10s. Never more than two web scenes in a row.
- Long-form: pattern interrupt every 10-20s. Open loops at section boundaries.

## Tension then payoff

State the headline, then the catch ("but it doesn't top the chart"), then the
verdict. Honesty retains trust.

## Attribution

Vendor claims are attributed ("Anthropic says..."). Independent benchmarks are
flagged. Never compare using numbers from different sources unless the page
does.
